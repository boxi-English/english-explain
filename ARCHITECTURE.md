# Initial architecture

The core unit is a learner-facing lesson bundle: input, context, expected interpretation, production task, feedback rubric, revision opportunity, and transfer task.

The platform must distinguish language correctness from communicative fit. Automated feedback should be inspectable and should not claim proficiency from a single response. Audio, transcript, timing, and visual layers should share stable item IDs so an accessible text path remains equivalent to the media path.

The first implementation will prefer pinned, offline-capable assets and explicit provenance. Personal learner records are outside this public repository.
